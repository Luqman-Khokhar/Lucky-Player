# Project guide: Lucky Player

Offline Android video player. Expo SDK 57, React Native 0.86, TypeScript, expo-router, Redux Toolkit,
expo-sqlite, and a local native module (`modules/vlc-player`, Kotlin + libVLC) for playback.

Workflows are documented as skills in `.claude/skills/` (plain Markdown, usable by any tool):

| Skill | Covers |
|---|---|
| `git-workflow` | Branches, commit message rules (never mention AI tools), push and pull requests |
| `run-app` | Debug build, Metro on port 8082, installing on the test phone, crash and freeze debugging |
| `release-apk` | EAS release APK and AAB builds under the personal Expo account |

Key facts:
- Android only. `android/` is generated by prebuild and git-ignored; do not edit it by hand.
- Never commit to `main` directly; use `feature/*` or `fix/*` branches and pull requests.
- Never commit `.env` (Expo access token), keystores, or build output.
- Run EAS only through `npm run eas…` / `scripts/eas.sh`, which enforce the project's Expo account.
